\section{はじめに}
% カーリングについての説明が消えている。たぶんスペースを増やすための調整をしているときに間違えて消してしまったのかな。4行ぐらいあったはず。OK
デジタルカーリング\cite{dc3}は，連続行動空間と実行時ノイズによる確率的不確定性を併せ持つ戦略ゲームである．また，カーリングは「氷上のチェス」と呼ばれるように数手先までの深い読みを要求される競技である．
このような連続行動空間においてモンテカルロ木探索(MCTS)は有効とされるが，先行研究\cite{owatari2016,kato2016}によるとMCTSを用いた候補手選択には計算コストの課題がある．

われわれの先行研究\cite{naka_gi58}では，候補手生成後の結果盤面に対して階層的クラスタリングを適用し，各クラスタの代表手のみを候補として残すことで探索対象を削減する手法を，原始モンテカルロ(多段探索を伴わない1段階評価)の枠組みで検討した．
本研究ではこの枠組みをMCTSへ拡張したものをClusterMedoidとして比較対象に加える．
しかし，ClusterMedoidの代表手選出は各クラスタ内で盤面的に最も中心的な候補(medoid)を機械的に選ぶのみであり，得点の観点からの手の良し悪しを一切考慮していない．
このため，先読みを考慮した候補手の選択や，同一クラスタ内に得点期待値の高い候補と低い候補が混在する場合には，代表手が必ずしも有望な手にならないという課題があった．

本研究では，まずこれらの課題に対し，クラスタの表現(結果盤面の類似性)は維持したまま，代表手の選出規則にのみ得点期待値を組み込む手法ClusterValueを提案し，性能を損なわないことを確認する．
その上で本研究の主眼として，\textbf{クラスタリングを適用したMCTSにおいて候補手やクラスタ構造がどのように振る舞うか}に着目する．
具体的には，クラスタリングが候補手を意味のあるエリアへどう分類するか，また探索深さを変えた際に手とクラスタ構造がどのように変化するかを分析し，結果盤面に基づくクラスタリングによる候補削減の可能性を明らかにする．これらの分析に加え, より多くの局面での統計的評価および得点期待値と実行時のリスクを統合したクラスタ価値の定義による分析の深化を示す予定である.


\section{提案手法: ClusterValue}

ClusterValueは，MCTSのルートノードにおいて以下の手順で候補手を選別する．
\begin{enumerate}
\setlength{\itemsep}{1pt}
\item 各候補手について，安価なロールアウト(既定3回)により得点期待値$\hat{E}[\mathrm{score}]$を推定する．
\item ClusterMedoidと同一の距離関数・階層的クラスタリング(平均連結法)により，結果盤面を基準に候補手をクラスタへ分割する．
\item 各クラスタの価値を，メンバー候補の$\hat{E}[\mathrm{score}]$の平均値として定義する．クラスタ単位で平均を取ることで，個々の候補の推定に含まれる分散を低減できる．
\item 価値上位$K$個のクラスタを採用し，各クラスタ内で$\hat{E}[\mathrm{score}]$が最大の候補を代表手としてMCTSの子ノードに割り当てる．全体の最良候補が属するクラスタは，価値順位によらず必ず採用する．
\end{enumerate}
% クラスタ数$K$は，プレイアウト予算$P$と子1個あたりに割り当てたい最低訪問数$V$(既定50)から $K=\max(1,\lfloor P/V \rfloor)$ として予算に応じ自動的に決定する．
% Kの話しは省略でもいいかも

ClusterMedoidとの差異は3・4のみであり，探索木の構造・ロールアウト方策・木の深さ以降の展開は共通である．
したがって両手法の比較は，「代表手選出規則を盤面中心性から得点期待値ベースへ変更した効果」を単離して評価できる．


\section{実験: クラスタリングを適用したMCTSの振る舞い}

\subsection{実験設定}
自己対戦から抽出した50局面$\times$5乱数系列に対し，AllGrid(全候補を子ノードとする基準手法)，ClusterMedoid(先行研究\cite{naka_gi58}をMCTSへ拡張した比較手法)，ClusterValue(提案手法)を等物理シミュレーション予算下で評価した．
各候補$a$を実行ノイズ込みで$K{=}200$回再試行し得点期待値$q(a)$を推定する審判機構を別途構築した(以下，$q(a)$を\textbf{審判値}と呼ぶ)．
各手法が選択した手の質は，同一局面での審判値の最大値$q^{*}$との差
\begin{equation}
\mathrm{regret} = q^{*} - q(a)
\label{eq:regret}
\end{equation}
により評価する(値が小さいほど良い)．
表\ref{tab:regret}に示すように，ClusterValueのregretはAllGrid・ClusterMedoidと同水準であり，Friedman検定でも有意差は見られなかった($p=0.88$)．
すなわち\textbf{ClusterValueは性能を損なうことなくClusterMedoidの代表手選出を改善できる}ことを確認した.

\subsection{クラスタリングによる候補手の意味的分類}
図\ref{fig:areamap}に，ある局面でClusterValueが生成したクラスタを示す．
結果盤面の類似性に基づくクラスタは，投球後の石の配置が近い候補手をまとめる傾向があり，各クラスタに得点期待値を対応付けることで，盤面上のどのエリアへの投球が有望かを可視化できる(エリア価値マップ)．

\label{fig:areamap}

このクラスタ分類が単なる次元削減ではなく戦略的に意味のある区分けになっているかを，クラスタ価値($\hat{E}[\mathrm{score}]$の平均)と審判値とのSpearman順位相関で検証した．
候補単位の相関(中央値$\rho\fallingdotseq0.30$)に対し，クラスタ単位の相関は中央値$\rho\fallingdotseq0.49$であり，\textbf{5乱数系列すべてで}クラスタ単位の方が高い精度を示した．
個々の候補の推定に含まれる分散が，クラスタ内で平均を取ることで低減された結果と考えられる．

\subsection{手の変化に伴うクラスタの変化}
手の選択が分かれた局面について，深さ1を探索した手と深さ3を探索した手が同一クラスタに属するか，別クラスタに属するかを50局面$\times$5乱数系列で調べた．
別クラスタへの乗り換えの割合は序盤89\%，中盤80\%，終盤52\%であり，\textbf{序盤・中盤では手が変わるとほぼ確実に別の戦術グループへ乗り換わる一方，終盤では約半数が同一クラスタ内の微調整にとどまる}という，ゲームの進行度による質的な違いが見られた．
乗り換え先のクラスタは常に複数候補を含んでおり(単独候補への収束ではない)，個々の候補ではなく戦術グループ単位で選択が再考されていることを裏付ける(乗り換え元は単独候補である場合も一部見られた)．
終盤の乗り換えでは，石を排除するヒットとドローの間の相互の変化が多く観察された．


\section{おわりに}

本研究では，結果盤面の類似性に基づくクラスタリングを用いたMCTSにおいて，候補手やクラスタ構造がどのように振る舞うかを分析した．
まずClusterValueにより，性能を損なうことなくClusterMedoidの代表手選出(価値盲目なmedoid選択)を改善できることを確認した．
その上で，(i)候補手は得点期待値の観点で意味のあるエリアへ分類されること，(ii)探索深さによる手の変化は個々の候補ではなく戦術グループ単位で生じ，その変化が別グループへの乗り換えか同一グループ内の微調整かはゲームの進行度によって傾向が異なることを明らかにした．
これらの結果は，一手を投じた後の盤面類似性に基づくクラスタリングにより，MCTS全体で調べるべき候補手をエリア単位で効率的に絞り込める可能性を示唆する．

現状の分析は事前に用意した局面集合に対するオフライン評価にとどまる. 局面数を拡大した統計的評価と, 得点期待値だけでなく, 実行時のリスクも考慮したクラスタ価値の定義による分析を詳細に行い, クラスタリングを用いた候補手削減がどのような局面でより有効に機能するのかを明らかにする予定である.
その後,時間制約下で対局可能な実装を行い,過去の大会優勝プログラムと対戦を通じて実践における有効性を検証する予定である.
