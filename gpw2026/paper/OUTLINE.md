## 5 性能面の評価 (前回の手法と比べてどれだけ良いか)
- 5.1 主結果: 提案 0.309 / 全探索 0.334 / 前回 0.396 (500局面×5seed, P=200)。前回より 22% 減 (282勝206敗, Holm p=2e-8)、等予算の全探索にも勝つ (p=3e-4)。外乱なしの比較でも 0.423 vs 0.488 (p=1e-3)。 [E14, E16]
- 5.2 何が効いたか: 外乱込み評価 (全探索 −0.084, ClusterValue −0.114、木の損失が半減) と価値に基づく選別 (同じ子数 4 のランダム選別 0.552 → 0.309)。前回の medoid はランダム選別と同等 (A2N≈A5N, p=0.79)。 [E13, E14, E16]
- 5.3 予算依存: 最終ショットを除くと全探索との差 −0.094 (P=100) → −0.002 (P=800)。全探索の約 5〜6 割の計算量で同品質 (検定なし)。 [E17]
- 5.4 前回の手法との差が出る局面: 最良手のクラスタの大きさ別。6〜10 で −0.090 (p=5e-8)、1〜2 では差なし (+0.007)。= medoid が大きいクラスタで価値の低い手を選ぶ。 [cluster_vs_topk/by_best_csize.txt]
- 図表: 手法の regret の表 (A1N / A2N / 提案 + 決定的評価版)、予算スイープの図。

## 6 視覚的評価 (クラスタで分けると何が見えるか)
- 6.1 クラスタは「行動の名前」ではなく「結果の種類」で手をまとめる。2 手以上のクラスタの 38% は種類の違う手 (ヒットとドロー等) を、75% は回転の違う手を含む。最終ショット以外では約 60 手 → 約 12 クラスタ、最大クラスタは候補の約 25%、クラスタの 27% は 1 手だけ。
- 6.2 クラスタ価値でエリアの有望さを示せる。審判値との順位相関が候補単位 0.27 → クラスタ単位 0.37 (p=4e-15)。 [E12]
- 6.3 **別の道**: 「今すぐ有利な手 A」と「今の得点は 2 点以上低いが審判値は最良級の手 B」が別のクラスタに分かれる局面 = 184/468 (39%)。B はドロー 73・ヒット 77・ポストガード 17・フリーズ 15。ただし提案の 4 手が A と B を両方含むのは 7% だけなので、別の道は「クラスタ全体の価値の地図」で見せる (B のクラスタの価値順位は中央値 5 位、上位 8 に 85%)。例: g1555 e2 s3 (後攻が今の 1 点を取りにいかず、サイドに置いて複数点を狙う) / g157 e5 s8 (先攻がハウスを片付けずに石を残す)。
- 6.4 **単独の結果を持つ最良手**: 最良手のクラスタが 1〜2 手の局面が非最終局面の 19% (混んだハウスでは 36%)。ダブルテイクアウト、レイズ、連鎖など。例: g7280 e3 s8 / g9633 e1 s10 / g4456 e4 s12。
- 6.5 前回の手法との違いが見える例: 同じクラスタでも、前回は真ん中の手 (medoid)、提案はそのクラスタで最良の手を示す。最良級クラスタの medoid が最良級である率は 45%。
- 図: (i) 1 局面の盤面 + クラスタごとの結果 (6.1/6.4)、(ii) 別の道の図 = A と B の結果盤面 + 「今の得点 vs 審判値」の散布図 (6.3)。

## 7 結果盤面による分割とボロノイ領域 (新設, VOOT と対応させる節)
- 7.1 対応関係: VOO は評価済みの行動を母点として行動空間をボロノイ分割し、最良の母点のセルを重点的に探す。提案手法は結果盤面の距離で候補を分割し、各クラスタを 1 つの代表で扱い、最良の候補を含むクラスタを必ず採用する (= 最良セルの重点探索)。
- 7.2 行動空間の近さ ≠ 結果の近さ: 行動空間 (初速 vx, vy と回転) で最も近い候補が別のクラスタに属する割合 = 45% (468 局面の中央値)。最近傍の |Δq| > 0.5 の割合は行動空間 3.9% / 結果盤面空間 1.9%。同じ狙いで強さが少し違うだけで結果が変わり、回転の違う手が同じ結果になる。
- 7.3 どちらの分割が価値のまとまった領域を作るか: 同じ数のセルに分けたときの η² (審判値の分散のうち分割で説明される割合)。結果盤面のクラスタ / 行動空間の k-means / 行動空間のボロノイ (ランダム母点 = VOO 型) / ランダム分割 = 0.549 / 0.422 (四分位範囲で尺度を合わせた版 0.393) / 0.375 / 0.193。結果盤面のクラスタが行動空間のどの分割にも有意に勝つ (対 k-means p=2e-28)。
- 7.4 意味づけ: VOOT が前提とする「近い行動は近い価値」は、カーリングでは行動空間より結果盤面空間で成り立ちやすい。結果盤面のクラスタは価値の地図の単位として適しており、そのまま人間に見せる単位 (6章) にもなる。今後の課題 = 結果盤面空間で VOO のように新しい手を生成する (有望なクラスタの周辺で候補を足す)。
- 図: (a) 1 局面の候補を行動空間に置き結果盤面クラスタで色分け、(b) 4 種の分割の η² の箱ひげ。
- 注意: distDelta はベクトル空間の距離ではないので「一般化したボロノイ領域 (最も近い代表に割り当てた領域)」と書く。平均連結法のクラスタは厳密にはボロノイ領域ではない。
