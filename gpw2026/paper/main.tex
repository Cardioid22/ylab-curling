\section{はじめに}
\label{sec:intro}

カーリングは，投石の速度と回転方向という連続値の行動を選ぶゲームであり，
狙いどおりに投げても実行時の誤差（以下，外乱）によって結果が確率的に変わる．
また「氷上のチェス」と呼ばれるように，数手先の石の配置を見越した読みが要求される．
デジタルカーリング~\cite{dc3}はこの競技を物理シミュレータ上で再現した対戦環境であり，
モンテカルロ木探索（MCTS）を中心とした思考エンジンが研究されてきた~\cite{owatari2016,kato2016,yee2016}．

連続行動空間でMCTSを用いる際には，ドロー・テイクアウト・ガードなどの候補手を有限個生成し，それを木の分岐とすることが多い．
しかし候補手を十分に用意すると分枝数が大きくなり（本研究の設定では1局面あたり33〜153手），
限られた計算予算のもとでは1つの候補手に割り当てられるシミュレーション回数が不足する．
% 出典: test_positions500 の候補数 N (平均 70.6, 中央値 61)
対戦では持ち時間が決まっているため，少ない計算量で良い手を選べることは実用上も重要である．
大きな行動空間や連続行動空間でのMCTSについては，
ボロノイ分割に基づいて行動をサンプリングするVOOT~\cite{kim2020voot}や，
学習した遷移モデルから状態ごとに不要な行動を除く状態条件付き行動抽象化~\cite{kwak2024}
などが提案されている（\ref{sec:related}章）．

われわれの先行研究~\cite{naka_gi58}では，各候補手を打った後の盤面（以下，結果盤面）に階層的クラスタリングを適用し，
各クラスタの代表手のみを探索対象に残すことで候補手を削減する手法を提案した．
結果盤面でクラスタリングするのは，外乱のあるカーリングでは「どこを狙ったか」よりも
「その手がどのような盤面を引き起こすか」によって手の役割が決まると考えたためである．
本論文では，この手法をMCTSに拡張したものをClusterMedoidと呼び，既存手法として扱う．
ClusterMedoidは，各クラスタの代表手として盤面的に最も中心的な候補（medoid）を選ぶ．
しかしこの選び方は手の得点期待値を考慮していないため，代表手が有望な手になるとは限らない．
実際，本論文の実験では，medoidによる代表手の選出は無作為な選出と同等の性能にとどまった（\ref{sec:perf-ablation}節）．
また先行研究では，全候補を探索する手法が選んだ手との一致率で性能を評価していたが，
計算予算が限られた全探索の選択は正解の代わりにならないという問題もあった．

そこで本論文では，結果盤面によるクラスタ表現は保ったまま，
クラスタの採用と代表手の選出に得点期待値を用いる手法ClusterValueを提案する．
ClusterValueは，各候補手の得点期待値を少数のロールアウトで安価に推定し，
その平均値（クラスタ価値）が高い上位のクラスタから，それぞれ推定値が最大の候補を代表手として探索木に残す．
さらに，木の中で手を評価するたびに外乱ありで打ち直す外乱込み評価を組み合わせ，
「狙った結果」ではなく「その手を試みる価値」を評価する．

性能は，各候補手を外乱込みで200回ロールアウトして求めた得点期待値（以下，審判値）を正解基準とし，
選んだ手と最良手との審判値の差（regret）で評価する．
層化抽出した500局面を対象に，物理シミュレーションの回数を揃えた等予算の条件で各手法を比較した．
本論文の貢献は，性能面の評価と，クラスタを人間が見て理解できるかという視覚的評価の2つからなる．
\begin{itemize}
\item 外乱込み評価のもとで，ClusterValueは前回の手法（ClusterMedoid）よりregretが22\%小さく，等予算の全探索（AllGrid）も有意に上回った．
その利得は計算予算が小さいほど大きい（\ref{sec:perf}章）．
% 出典: gpw_experiment/paper_numbers/numbers.txt (500局面 x 5seed, P=200) A9P5N 0.309 / A1N 0.334 / A2N 0.396
\item 結果盤面のクラスタによって，相手の中心の石を取り除くような他と似ていない最良手や，
今の得点は低いがエンド全体では同等に有利な別の手を，盤面の図として示せることを示した（\ref{sec:visual}章）．
\item 結果盤面による分割が，VOOのような行動空間の分割よりも価値のまとまった領域を作ることを示した（\ref{sec:voronoi}章）．
\end{itemize}

本論文の構成は以下のとおりである．
\ref{sec:related}章で関連研究を述べ，\ref{sec:method}章で既存手法と提案手法を説明する．
\ref{sec:setup}章で評価設定を述べ，\ref{sec:perf}章で性能面の評価，\ref{sec:visual}章で視覚的評価を示す．
\ref{sec:voronoi}章では結果盤面による分割をボロノイ領域の観点から検討し，\ref{sec:discussion}章で考察を述べる．

\section{関連研究}
\label{sec:related}

\subsection{デジタルカーリングの思考エンジン}
\label{sec:related-curling}

デジタルカーリングでは，候補手を有限個に絞ったうえで探索する手法が主に研究されてきた．
大渡ら~\cite{owatari2016}は，MCTSに基づく思考エンジン「歩」を開発した．
歩は，ドロー，ヒット，フリーズ，ガードなどのショットの種類ごとに盤面に応じた候補手を生成し，
UCB1によって有望な候補手に多くのプレイアウトを配分する．
本論文の候補手生成も，歩の候補手生成を参考にしている．
% 実装: src/shot_generator generatePool (歩相当. ComeAround/Peel 等は未生成; experiments/REINVESTMENT_EXPERIMENT_GUIDE.md)
加藤ら~\cite{kato2016}は，行動空間をグリッドで離散化し，不確定性を考慮したExpectimax探索を行った．
いずれの手法でも1局面あたりの候補手は多く，探索を深くするうえでの障害となっていた．

Yeeら~\cite{yee2016}は，カーリングのシミュレータを対象に，実行時の誤差のモデルをカーネルとするカーネル回帰によって，
行動の価値の推定を周辺の行動へ汎化するKR-UCTを提案した．
KR-UCTは，ある行動の試行で得られた結果を近い行動の評価にも用い，初期の候補手の外側にある行動も探索する．
Leeら~\cite{lee2018curling}は，カーネル回帰による連続行動の木探索を深層ニューラルネットワークと組み合わせ，
教師あり学習と自己対戦による強化学習でデジタルカーリングのプログラムを構築した．
KR-UCTが行動のパラメータ空間での近さによって情報を共有するのに対し，本論文は結果盤面の近さによって候補手をまとめる．
そのため，回転方向が異なり行動のパラメータとしては離れた2つのドローでも，同じ位置に止まれば同じクラスタに入りうる．
またYeeらは，良い手を含めるために候補を増やすことと，有望な候補を正確に評価することの間にトレードオフがあると指摘している．
\ref{sec:perf-ablation}節で行うregretの分解は，このトレードオフを等予算の条件で定量化したものと位置づけられる．

\subsection{連続・大規模な行動空間でのMCTS}
\label{sec:related-continuous}

連続行動空間でのMCTSには，各ノードで「どの行動を試すか」を連続空間上の最適化の問題として扱う手法がある．
HOOT~\cite{mansley2011hoot}は，行動空間を階層的に分割しながら価値の高い領域に試行を集中させる連続腕バンディットのアルゴリズム（HOO）を，木の各ノードに適用した．

Kimら~\cite{kim2020voot}のVOOTは，木の各ノードで，ボロノイ分割に基づくブラックボックス最適化VOOによって行動をサンプリングする．
VOOは，それまでに評価した行動を母点とするボロノイ分割を用いる．
確率$\omega$では行動空間全体から一様に，すなわち各ボロノイセルの体積に比例してサンプリングし，
確率$1-\omega$では現在の最良の行動のボロノイセルの中からサンプリングする．
分割は陽に構成せず，母点との距離だけで扱えるため，高次元の行動空間にも適用できる．
VOOTは決定的な遷移をもつ高次元の連続行動の問題を対象とし，regretの上界も示されている．

本論文の手法は，候補を領域に分けて各領域を1つの代表で扱い，最良の候補を含む領域に探索を集中させる点で，VOOと共通する．
とくに，ClusterValueが推定値の最も高い候補の属するクラスタを必ず採用する規則（\ref{sec:method-value}節）は，
VOOが最良の行動のボロノイセルを重点的に探索することに対応する．
一方で，次の3点が異なる．
第一に，VOOは行動のパラメータ空間を行動どうしの距離で分割するが，本論文は結果盤面どうしの距離で候補手を分割する．
カーリングでは，わずかな狙いの違いで石に当たるかどうかが変わって結果が大きく変わる一方，
離れた行動が同じ結果を生むこともあるため，行動空間での近さは手の役割の近さを必ずしも意味しない．
第二に，VOOTは決定的な遷移を前提とするが，カーリングには外乱があり，同じ行動でも結果がばらつく．
本論文では，クラスタは外乱なしの結果盤面から作り，価値は外乱込みで評価することでこれに対処する（\ref{sec:method-noisy}節）．
第三に，VOOTは行動を新たに生成するのに対し，本論文は候補手生成器が作った有限個の候補から選別する．
両者は排他的ではなく，有望なクラスタの周辺で新たな候補を生成するといった組み合わせも考えられる．
この対応関係と，どちらの空間で分割するのがよいかは，\ref{sec:voronoi}章で定量的に検討する．

また，確率的な遷移をもつ問題では，木のノードを状態ではなく行動の系列に対応させ，
プレイアウトのたびに遷移を標本化し直すopen-loop型の探索も用いられる~\cite{perez2015openloop}．
本論文の外乱込み評価（\ref{sec:method-noisy}節）は，この考え方を価値の評価に用いたものである．

\subsection{状態と行動の抽象化}
\label{sec:related-abstraction}

MCTSの分枝を減らす別の方向として，等価な状態や行動をまとめる抽象化がある．
Hostetlerら~\cite{hostetler2014}はMCTSにおける状態の集約を扱った．
ASAP-UCT~\cite{anand2015asap}は，抽象状態への遷移確率と即時コストが等しい状態行動対を等価とみなし，
等価な対どうしで木の価値の更新を共有する．
OGA-UCT~\cite{anand2016oga}は，この抽象化を探索の途中で逐次計算する．
これらは等価性が成り立つ状態や行動をまとめるものであるが，
石の位置が連続値であるカーリングでは，異なる手の結果盤面が厳密に一致することはほとんどない．

Kwakら~\cite{kwak2024}は，行動が複数の部分行動の組み合わせからなる問題を対象に，状態条件付き行動抽象化を提案した．
この手法は，潜在ダイナミクスモデルと補助ネットワークを学習して，現在の状態からの遷移に関係する部分行動を推定し，
木の各ノードで遷移に関係しない部分行動の探索を省くことで探索空間を縮小する．
本論文の手法も，ノードごとにその局面での行動の結果に基づいて行動をまとめる点で，状態条件付きの行動抽象化の一種とみなせる．
ただし，Kwakらが学習したモデルから遷移への寄与を推定するのに対し，本論文はシミュレータで得た結果盤面を直接用いるため，学習を必要としない．
また，Kwakらは決定的な遷移のもとで部分行動の単位で冗長性を判定するが，
本論文は外乱のある環境で，行動全体を結果盤面の近さに基づいて近似的にまとめる．

近似的な抽象化では，同じまとまりの中に価値の異なる行動が混在しうる．
本論文の結果は，このような場合には，まとまりの作り方に加えて，まとまりの中からどの行動を代表として残すかが性能を左右することを示している．
実際，medoidによる代表手の選出は無作為な選出と同等であり，
全探索を上回ったのは得点期待値に基づいてクラスタと代表手を選んだ場合であった（\ref{sec:perf-ablation}節）．
% 出典: E14/E16 (A2N≈A5N p=0.79, A9P5N 0.309 < A1N 0.334 < A2N 0.396)

\section{提案手法}
\label{sec:method}

\subsection{探索の枠組み}
\label{sec:method-mcts}

本論文で比較する手法は，いずれも同じMCTSの枠組みを用い，各ノードでどの候補手を子として残すかだけが異なる．
各ノードでは，候補手生成器が$N$個の候補手$a_1,\dots,a_N$（ドロー，ヒット，フリーズ，ガードなど）を生成し，
それぞれを外乱なしでシミュレーションして結果盤面$s_1,\dots,s_N$を求める．
探索は深さ3まで木を展開し，プレイアウト予算$P$回の反復を行う．
子の選択にはUCB1を用い，各ノードではそのノードで手番を持つ側にとっての価値を最大化する（negamax）．
葉ではロールアウト方策でエンドの終わりまで$R$回ロールアウトし，その平均を価値とする．
報酬は，探索を開始した手番側から見た現在のエンドの純得点である．
エンドの最終ショットを越える枝は終端とし，そのエンドの得点を報酬とする．
探索後は，ルートの子のうち訪問回数が最大の手を選ぶ．
ロールアウト方策と各パラメータの値は\ref{sec:setup}章で述べる．

全候補を子とする手法をAllGridと呼ぶ．AllGridは候補の取りこぼしがない代わりに，
ルートの子が平均70.6個となり，$P=200$では1つの子あたりの訪問回数が少なくなる．
% 出典: test_positions500 の N の平均

\subsection{既存手法：ClusterMedoid}
\label{sec:method-medoid}

ClusterMedoidは，先行研究~\cite{naka_gi58}の候補削減をMCTSの各ノードに適用した手法である．
まず，結果盤面どうしの距離$d(s_i, s_j)$を，盤面の戦術的な違いを捉える次の8項目の重み付き和として定義する．
\begin{enumerate}
\setlength{\itemsep}{0pt}
\item 元の盤面にあった石の移動量の差
\item 投げた石の停止位置の差
\item 石の有無（場外に出たかどうか）の不一致
\item 石が属する領域（ハウス内，ガードゾーン，それ以外）の不一致
\item 既存の石に触れたかどうかの不一致
\item 投げた石と最も近い石との距離の差
\item その時点で数えた得点の差
\item ハウスの中心に最も近い石を持つチームの不一致
\end{enumerate}
% 実装: experiments/mcts_shared.cpp distDelta (重み 2/4/30/12/15/5/8/10)
% TODO: 重みを表で示すか，先行研究~\cite{naka_gi58}を参照するだけにするか決める
この距離に基づき，平均連結法による階層的クラスタリングで候補手を$K_c = \lceil rN \rceil$個のクラスタに分割する（$r=0.2$）．
各クラスタからは，クラスタ内の他の候補との距離の総和が最小となる候補（medoid）を代表手とし，
すべてのクラスタの代表手を子とする．
評価に用いた500局面では，ルートの子の数は平均14.4個であった．
% 出典: RESEARCH_OUTLINE §7 (N=33〜153, 平均 70.6, K=ceil(0.2N) の実測平均 14.4)

ClusterMedoidの代表手の選び方は，盤面の中心性のみに基づいており，手の得点期待値を考慮していない．
そのため，同じクラスタに得点期待値の高い候補と低い候補が混在する場合や，
得点期待値の低いクラスタが多数を占める場合には，有望でない手に探索予算が割かれる．

\subsection{ClusterValue}
\label{sec:method-value}

ClusterValueは，ClusterMedoidのクラスタ表現（結果盤面に基づくクラスタ）を保ったまま，
クラスタの採用と代表手の選出の規則に得点期待値を組み込んだ手法である．
ルートノードでは次の手順で子を決める．
\begin{enumerate}
\setlength{\itemsep}{0pt}
\item \textbf{得点期待値の推定}：
各候補手$a_i$について，その結果盤面からロールアウトを$R_{\mathrm{pre}}$回行い，
エンドの純得点の平均$\hat{e}_i$を求める．
候補手を打った時点でエンドが終わる場合は，そのエンドの得点をそのまま用いる．
\item \textbf{クラスタリング}：
ClusterMedoidと同じ距離と手順で，候補手を$K_c$個のクラスタ$C_1,\dots,C_{K_c}$に分割する．
\item \textbf{クラスタ価値の計算}：
各クラスタの価値を，メンバーの推定値の平均
\begin{equation}
v(C_c) = \frac{1}{|C_c|}\sum_{i \in C_c} \hat{e}_i
\label{eq:cluster-value}
\end{equation}
とする．
\item \textbf{子の選択}：
クラスタを価値の高い順に並べ，上位$K$個のクラスタから，それぞれ$\hat{e}_i$が最大の候補を代表手として子にする．
ただし，全候補の中で$\hat{e}_i$が最大の候補が属するクラスタは，価値の順位によらず必ず採用する．
\end{enumerate}
子の数$K$は，子1つあたりに確保したい訪問回数$V$を用いて$K=\max(1, \lfloor P/V \rfloor)$とする．
本論文では$V=50$とし，$P=200$のとき$K=4$である．
深さ1以降のノードでは，ClusterMedoidと同じ規則で子を作る．
% TODO: 深さ1以降を ClusterMedoid にした理由を書くか (事前ロールアウトのコスト / A10 は修正木で再評価していない)

手順1の推定は$R_{\mathrm{pre}}$回（本論文では5回）のロールアウトによるため，個々の候補の推定値はばらつきが大きい．
手順3でクラスタ単位の平均を取ることで，このばらつきを抑えたうえでエリア単位の有望さを比較できる．
一方，代表手はクラスタ内で推定値が最大の候補とし，クラスタ内の優劣も選択に反映する．

\subsection{外乱込み評価}
\label{sec:method-noisy}

\ref{sec:method-mcts}節の木は，外乱なしでシミュレーションした結果盤面を子の状態とする．
この決定的な評価では，各手は「狙いどおりに投げられた場合」の価値で評価される．
一方，実際の対戦では手は外乱を伴って実行されるため，
わずかなずれで結果が大きく変わる手は，決定的な評価では過大評価されやすい．
本論文で正解基準とする審判値も，外乱ありで打ち直した結果の平均，すなわち「その手を試みる価値」である．

そこで外乱込み評価では，木の構造（候補手の生成，クラスタリング，候補の選別）は外乱なしの結果盤面から作ったまま，
価値の評価だけを外乱込みで行う．
具体的には，プレイアウトのたびに，選んだ手をその時点で到達している実際の盤面から外乱ありでシミュレーションし直し，
得られた盤面を次のノードへ運ぶ．
葉のロールアウトも，この外乱込みで到達した盤面から行う．
ClusterValueの事前推定（手順1）でも，候補手を毎回外乱ありで打ち直してからロールアウトする．
これにより，各ノードの価値は「その手順を外乱のもとで試みたときの得点期待値」の推定となる．
これは，木のノードを行動の系列に対応させるopen-loop型の探索~\cite{perez2015openloop}の考え方を，価値の評価に用いたものである．
% 実装: --noisy-tree (experiments/reinvest_experiment.cpp runPlayout / estimateRootScores)

外乱込み評価は候補の選別方法とは独立であり，AllGridやClusterMedoidにも適用できる．
以下，外乱込み評価を適用した手法を「手法名+N」と表記する（例：AllGrid+N）．
本論文の提案手法は，ClusterValue（$R_{\mathrm{pre}}=5$）に外乱込み評価を組み合わせたClusterValue+Nである．
\ref{sec:perf}章では，各手法を決定的評価と外乱込み評価の両方で比較する．

\subsection{局面と候補手}

層化して抽出しているため，以下で述べる局面の割合は実戦での出現頻度とは異なる．
エンドの最終ショットの局面は32局面（6.4\%）である．
候補手は1局面あたり33〜153手（平均70.6手）であった．

\subsection{探索とシミュレーション}
\label{sec:setup-search}

物理シミュレーションにはデジタルカーリング~\cite{dc3}のシミュレータを用い，
外乱は同環境の標準の設定（初速の大きさと向きに正規分布の誤差．標準偏差はそれぞれ0.0076\,m/s，0.0018\,rad）とした．
% 出典: extern/DigitalCurling3 player_normal_dist_factory.hpp (stddev_speed, stddev_angle の既定値)
探索は深さ3，プレイアウト予算$P=200$とし，葉では$R=10$回のロールアウトを行う．
ロールアウト方策は，各手番でハウスを覆う位置へのドロー，相手のNo.1ストーンへのヒットなど6〜10個の候補を生成し，
確率0.3で無作為に，それ以外は1投後の盤面で数えた得点が最大となる候補を選ぶ．
ロールアウトの投球は外乱ありでシミュレーションする．
% 実装: experiments/mcts_shared.cpp rolloutFromState (epsilon=0.3), ShotGenerator::generateRolloutCandidates
ClusterMedoidとClusterValueのクラスタ数は$K_c=\lceil 0.2N \rceil$，
ClusterValueの事前推定は$R_{\mathrm{pre}}=5$回，子の数は$K=4$とした（\ref{sec:method-value}節）．
各手法を乱数のシード5通りで実行した．

\subsection{審判値とregret}
\label{sec:setup-referee}

正解の基準として，各局面の全候補手について，候補手を外乱ありで打ち直してからエンドの終わりまでロールアウトすることを200回繰り返し，
手番側から見たエンドの純得点の平均を求めた．これを審判値$q$と呼ぶ．
審判値は「その手を試みる価値」の推定であり，探索木を用いないため各手法の実装に依存しない．
手法が選んだ手$a$のregretを$q^{*}-q(a)$とする．ここで$q^{*}$は局面内の審判値の最大値である．

審判値の標準誤差は約0.10点であるが，1位と2位の候補の審判値の差は中央値で0.073点とこれより小さく，
約7割の局面では「どの手が最良か」自体が不安定である．
そのため，先行研究~\cite{naka_gi58}で用いた最良手との一致率ではなく，値の差であるregretで評価する．
% 出典: E06 (審判の監査)

\subsection{比較手法と統計}
\label{sec:setup-methods}

比較する手法は，AllGrid，ClusterMedoid，ClusterValue（\ref{sec:method}章）と，候補を無作為に選ぶ2つの対照である．
RandomKはClusterMedoidと同じ数（$\lceil 0.2N \rceil$個）の候補を，RandomK4はClusterValueと同じ4個の候補を，
それぞれ無作為に選んでルートの子とする．
各手法を決定的評価と外乱込み評価（+N）で実行した．ただしRandomK4は外乱込み評価のみである．

予算はプレイアウト回数$P$で揃えた．
このとき1局面あたりの物理シミュレーション回数は，事前推定の分だけClusterValue+NがAllGrid+Nより3.6\%多い．
% 出典: RESEARCH_OUTLINE §2.5 (500局面, A9P5N 75.7k / A1N 73.1k)
本論文の比較はシミュレーション回数を揃えたものであり，実時間の比較ではない．

統計検定は，局面ごとに5シードのregretを平均して1つの値とし，
9条件（\tabref{tab:main}）のFriedman検定の後，全36対についてWilcoxonの符号順位検定を行い，Holm法で補正した~\cite{demsar2006}．
以下では補正後の$p$値を示す．

\subsection{何が効いたか}
\label{sec:perf-ablation}

\tabref{tab:main}の差を，外乱込み評価，価値に基づく選別，候補を絞ることの3つに分けて見る．

\paragraph{外乱込み評価}
外乱込み評価は，候補の選び方によらずregretを大きく下げた（AllGridで$-0.084$，$p=3\times10^{-4}$．ClusterValueで$-0.114$，$p=9\times10^{-15}$）．
regretを，選別で最良手を落とした損失（選別損失．$q^{*}$と，子に残った候補の審判値の最大値との差）と，
残りの損失（木の損失）に分けると，ClusterValueの選別損失は0.230から0.211とほぼ変わらず，
木の損失が0.193から0.098に半減していた．
% 出典: E13 (A9P5 -> A9P5N)
つまり改善は，残した子の評価が正確になったことによる．
また，選んだ手の審判値の標準偏差は外乱込み評価の有無によらず1.68であった．
外乱込み評価は安全な手を好むようになったのではなく，外乱のもとで実際に実現する価値の高い手を選ぶようになったと解釈できる．
ただし審判値も外乱込みで求めているため，この改善の一部は，木の評価の規約を正解基準の規約に揃えたことによる．
同じ規約どうしの比較（AllGrid+NとClusterValue+N）は公平である．

\paragraph{価値に基づく選別}
子の数が同じ4個どうしで比べると，無作為に選ぶRandomK4+Nの0.552に対し，ClusterValue+Nは0.309であった
（382勝115敗，$p=1\times10^{-43}$）．
一方，前回の手法のmedoidによる選出は，同じ数を無作為に選ぶ場合と差がなかった
（外乱込みで0.396対0.383，決定的評価で0.488対0.491，いずれも$p>0.8$）．
結果盤面のクラスタで候補を分けても，その中からどの手を残すかを価値で決めなければ性能は上がらない．

\paragraph{候補を絞ることの利得}
AllGrid+Nは全候補を子に持つため選別損失は0であり，regret 0.334はすべて木の損失である．
これに対してClusterValue+Nは，選別損失0.211を払う代わりに木の損失を0.098に抑えている．
$P=200$では，平均70.6個の子に予算を分散させると各子の評価が不十分になり，
選別による損失を払ってでも少数の有望な子を厚く評価した方が良い手を選べる．
% 出典: E13 (A9P5N screen_loss 0.211 / tree_loss 0.098), E14 (A1N 0.334)

\label{sec:visual-cases}

\figref{fig:cases}に2つの局面を示す．どちらも相手（青）がハウスの中心に最も近い石を持ち，手番の橙が負けている局面である．

局面g9633（第2エンド第11投，今の得点$-1$）では，ボタン上の相手のNo.1に弱く当てると，その石と奥の相手の石がともにプレーの外に出て（奥の自分の石も1個出る），
投げた石が中心の手前に残る（(c)）．
今の得点は$-1$から$+4$になり，審判値$+0.57$は全87手の中で最大である．

局面g964（第1エンド第9投，今の得点$-2$）では，相手のNo.1の手前にあるNo.2に弱く当てると，
No.2がプレーの外に出ると同時にNo.1が奥へ押しやられ，投げた石がNo.2のあった位置の近くに残る（(c)）．
今の得点は$-2$から$+2$になり，審判値$-0.29$は全63手の中で最大である．
% 出典: gpw_experiment/cluster_vs_topk/export/export_g964_e0_s8 (候補45: 相手 No.2 は除去, No.1 は 0.36m -> 1.21m)

この2つの最良手は，いずれも相手の中心の石を取り除き，自分の石を中心に近い位置に並べる手であり，人間が見ても意図が分かる．
一方で，これらの手の結果盤面は他のどの候補とも似ておらず，最良手のクラスタはg9633で2手，g964で1手であった．
クラスタに分けると，こうした手は多数のドローやガードの変種に埋もれず，独立したまとまりとして現れる．
提案手法は，探索に使う4つの子にこれらの最良手を5シード中それぞれ2回と5回残し，regretは0.10と0.07であった
（AllGrid+Nは0.22と0.24）．
ClusterMedoid+Nもすべてのクラスタの代表を子に持つため，これらの最良手を子に残す（regretは0.19と0.04）．
% 出典: gpw_experiment/cluster_vs_topk/catalog/index.csv (reg_A9P5N / reg_A1N / reg_A2N, 5seed平均)

\subsection{最良手が単独の結果を持つ局面}
\label{sec:visual-small}

最良手のクラスタが1〜2手の局面は，468局面中91局面（19\%）あった．
局面の型別では，石の多い局面で36\%（122局面中44局面）と多く，ドローやフリーズが有効な型の局面では約9\%であった．
91局面の最良手のうち63手はヒットであり，相手の石を2個以上出す手が22手，自分の石を中心へ押し込む手（レイズ）が18手あった．
% 出典: gpw_experiment/cluster_vs_topk/README.md (図カタログ: 最良手のクラスタが小さい 91 局面)
これらの局面では，提案手法の4つの子に最良手が残る割合が46\%（455回中208回）と，それ以外の局面の14\%より高かった．
% 出典: gpw_experiment/paper_numbers/numbers.txt (6.3)
1手だけのクラスタはクラスタ価値が平均で薄まらないため，推定値の高い単独の手はそのまま採用されやすい．

\subsection{別の道：今の得点は低いが同等に有利な手}
\label{sec:visual-paths}

\figref{fig:cases}(d)には，同じ局面で最良手とは別のクラスタに属し，今の得点は2点以上低いが審判値は最良に近い手Bを示した．
g9633のBは相手のNo.1に軽く当てる手で，今の得点は$-1$のままだが，審判値は$+0.36$（最良との差0.21）である．
g964のBはハウスの奥を狙ったドローで，手前の石に当たって止まる．今の得点は$-2$のままだが，審判値は$-0.43$（差0.14）である．
g964では，今すぐ2点を得る最良手Aでも，エンドの最後まで見た期待値は$-0.29$にとどまる．
今の得点だけでは見えない，後の展開まで含めた価値の近さが，別のクラスタの手として現れている．

一般に，審判値が最良から0.25以内のクラスタ（最良級クラスタ）のうち，その中で最良の手の今の得点が最大のものをA，
Aより今の得点が2点以上低い最良級クラスタをBとすると，AとBが別のクラスタに分かれる局面は468局面中184局面（39\%）あった．
Bの手はヒット77，ドロー73，ポストガード17，フリーズ15，プレガード2であった．
% 出典: gpw_experiment/cluster_vs_topk/paths_and_spaces_summary.txt
探索に使う4つの子がAとBを両方含むのは7\%にすぎないが，Bのクラスタのクラスタ価値の順位は中央値で12個中5位であり，
85\%の局面で上位8位以内に入った．
したがって別の道は，探索の子としてではなく，クラスタ価値の順に並べた結果盤面の一覧として人間に示すのが適している．
クラスタ単位の価値は候補単位の推定値より審判値との順位相関が高い（200局面，決定的評価で中央値0.27から0.37，$p=4\times10^{-15}$）ため，
この一覧の順位は個々の候補の推定値の順位より信頼できる．
% 出典: E12 (run200, A9P5 決定的評価, R_pre=5)

\section{結果盤面による分割とボロノイ領域}
\label{sec:voronoi}

\subsection{VOOとの対応}
\label{sec:voronoi-corr}

VOO~\cite{kim2020voot}は，評価済みの行動を母点として行動空間をボロノイ分割し，最良の母点のセルの中を重点的に探索する（\ref{sec:related-continuous}節）．
提案手法も，候補を領域に分けて各領域を1つの代表で扱い，推定値が最大の候補を含むクラスタを必ず採用する．
各候補を最も近い代表に割り当てた領域を，結果盤面の距離による一般化したボロノイ領域とみなせば，
ClusterValueはVOOと同様に「最良の領域を重点的に探す」方法と位置づけられる．
ただし距離$d$はベクトル空間の距離ではなく，平均連結法のクラスタは厳密にはボロノイ領域ではない．
両者の本質的な違いは，どの空間で近さを測るかにある．
そこで，VOOが前提とする「近い行動は近い価値を持つ」という性質が，行動空間と結果盤面の空間のどちらでよく成り立つかを調べた．

\begin{figure*}[t]
\centering
\includegraphics[width=\textwidth]{figures/fig_action_vs_result.png}
\caption{行動空間と結果盤面の空間．(a) 局面g1555 e2 s3の候補を行動空間（初速$v_x$，$v_y$）に置き，結果盤面のクラスタで色分けしたもの（価値の高い10クラスタに色を付けた．強いヒットなど7手は描画範囲外）．
(b) 468局面で，候補を同じ数の領域に分けたときの$\eta^2$（審判値の分散のうち，領域の違いで説明される割合）}
\ecaption{Action space versus result space.}
\label{fig:space}
\end{figure*}

\subsection{行動空間での近さと結果の近さ}
\label{sec:voronoi-nn}

行動空間は，初速$(v_x, v_y)$と回転方向の3次元とした．$v_x$と$v_y$は局面ごとに標準化し，回転の違いは1単位とした．
\figref{fig:space}(a)は，局面g1555（第3エンド第4投）の55手を行動空間に置き，結果盤面のクラスタで色分けしたものである．
同じ狙いで強さだけが違う手（縦に並ぶ点）が別のクラスタに分かれ，回転の違う手（○と△）が同じクラスタに入っている．
468局面で見ると，行動空間で最も近い候補が別のクラスタに属する割合は，中央値で45\%であった．
また，最も近い候補との審判値の差（中央値）は，行動空間では0.140，結果盤面の距離では0.130であり，
結果盤面で近い候補の方が価値も近かった（290勝146敗，$p=6\times10^{-15}$）．
最も近い候補との審判値の差が0.5点を超える割合は，行動空間で3.9\%，結果盤面で1.9\%であった．
% 出典: gpw_experiment/cluster_vs_topk/paths_and_spaces_summary.txt (局面ごとの値の中央値; Wilcoxon)

\subsection{価値のまとまった領域を作る分割}
\label{sec:voronoi-eta}

候補を同じ数の領域に分けたとき，審判値の分散のうち領域の違いで説明される割合$\eta^2$を比べた（\figref{fig:space}(b)）．
結果盤面のクラスタの$\eta^2$は中央値0.549であり，行動空間のk-means（0.422）と，
候補から無作為に選んだ母点による行動空間のボロノイ分割（VOOのセルに相当，20回の平均，0.375）のいずれよりも大きかった
（対k-meansで333勝135敗，$p=2\times10^{-28}$．対ボロノイ分割で385勝83敗，$p=3\times10^{-55}$）．
k-meansで$v_x$，$v_y$を四分位範囲で割って尺度を合わせた場合も0.393であった．
結果盤面のクラスタには1手だけのクラスタが多く，それだけでも$\eta^2$は大きくなりうる．
そこで，クラスタと同じ大きさの領域に無作為に分けた場合（0.193）を対照として示した．
% 出典: gpw_experiment/cluster_vs_topk/paths_and_spaces_summary.txt, scripts/analyze_paths_and_spaces.py

\subsection{意味づけ}
\label{sec:voronoi-meaning}

以上から，VOOTが前提とする「近い行動は近い価値を持つ」という性質は，カーリングでは行動空間より結果盤面の空間でよく成り立つ．
狙いがわずかに違うだけで石に当たるかどうかが変わる一方，離れた行動が同じ結果を生むためである．
結果盤面のクラスタは価値のまとまった領域であり，探索で価値を推定する単位としても，\ref{sec:visual}章のように人間に示す単位としても適している．
今後は，VOOが最良のセルの中で新たな行動を生成するのと同様に，有望なクラスタの結果を生む行動の周辺で新たな候補を生成することが考えられる．

\section{考察}
\label{sec:discussion}

\ref{sec:perf}章の結果から，性能向上をもたらしたのは，外乱込み評価と，得点期待値に基づく候補の選別である．
前回の手法のようにクラスタの中心的な手を代表にするだけでは，無作為に選ぶ場合と変わらなかった．
クラスタリングは，それ自体で良い手を選ぶ仕組みではなく，価値の情報と組み合わせることで意味を持つ．

一方でクラスタリングは，探索の結果を人間に示すうえで次の役割を果たす．
第一に，候補を結果の種類でまとめるため，60手前後の候補を12個程度の盤面の型として示せる（\ref{sec:visual-kind}節）．
第二に，相手の中心の石を取り除く手のように，結果が他のどの候補とも似ていない最良手は独立したクラスタになり，
多数の似た手に埋もれずに示される（\ref{sec:visual-cases}節，\ref{sec:visual-small}節）．
第三に，今の得点は低いがエンド全体では同等に有利な別の道を，クラスタ価値の順位とともに示せる（\ref{sec:visual-paths}節）．
これらは，クラスタが価値のまとまった領域になっていること（\ref{sec:voronoi}章）に支えられている．

\section{おわりに}
\label{sec:conclusion}

本論文では，結果盤面のクラスタ表現を保ったまま，クラスタの採用と代表手の選出に得点期待値を用いるClusterValueと，
外乱込み評価を組み合わせた候補削減を提案した．
500局面の等予算比較で，提案手法は前回の手法ClusterMedoidよりregretが22\%小さく，等予算の全探索も上回った．
その利得は計算予算が小さいほど大きく，全探索の約5〜6割の計算量で同程度の品質が得られた．
また，クラスタは手を結果の種類でまとめ，相手の中心の石を取り除くような他と似ていない最良手や，
今の得点は低いが同等に有利な別の道を，盤面の図として示せることを確認した．
結果盤面による分割は，VOOのような行動空間の分割よりも価値のまとまった領域を作った．
今後の課題は，結果盤面の空間で有望な領域の周辺に新たな候補を生成すること，
クラスタによる提示が人間の判断に役立つかを確かめること，持ち時間のある対戦で評価することである．
