\section{はじめに}
カーリングは，氷上で石（ストーン）を滑らせ，ハウスと呼ばれる同心円の的の中心（ティー）にどれだけ近づけられるかを競う競技である．
「氷上のチェス」と呼ばれるように，数手先の石の配置を見越した読みが要求される．
デジタルカーリング~\cite{dc3}は，この競技を2次元の物理シミュレータ上で再現した対戦環境であり，
モンテカルロ木探索（MCTS）を中心とした思考エンジンが研究されてきた~\cite{owatari2016,kato2016,yee2016}．

試合は複数のエンドからなり，各エンドでは2チームが交互に8投ずつ，計16投を投げる．
エンドの終わりに，ティーに最も近い石（No.1ストーン）を持つチームが，相手チームの最もティーに近い石より内側にある自チームの石の数だけ得点する．
得点に数えるのはハウスの中の石だけである．
エンドの最終投を投げる後攻は，最後に石の配置を変えられるため有利である．
主なショットには，狙った位置に石を止めるドロー，他の石に当てて動かすヒット，相手の石に密着させて止めるフリーズ，
ハウスの手前に石を置いて後ろの石を守るガードがある．
ガードのうち，ハウスの中の自分の石の前に置くものをポストガード，ハウスの手前の決まった位置に置くものをプレガードと呼ぶ．
また，自分の石に当ててティーの方へ押し込むヒットをレイズと呼ぶ．
デジタルカーリングでは，プレイヤは1投ごとに石の初速$(v_x, v_y)$と回転方向（時計回りか反時計回り）を選ぶ．
行動は連続値であり，さらに初速には正規分布に従う誤差（以下，外乱）が加わるため，狙いどおりに投げても結果は確率的に変わる．

連続行動空間でMCTSを用いる際には，ドロー，ヒット，ガードなどの候補手を有限個生成し，それを木の分岐とすることが多い．
しかし候補手を十分に用意すると分枝数が大きくなり（本論文の設定では1局面あたり33〜153手），
限られた計算予算のもとでは1つの候補手に割り当てられるシミュレーション回数が不足する．
対戦では持ち時間が決まっているため，少ない計算量で良い手を選べることは実用上も重要である．
大きな行動空間や連続行動空間でのMCTSについては，
ボロノイ分割に基づいて行動をサンプリングするVOOT~\cite{kim2020voot}や，
学習した遷移モデルから状態ごとに不要な行動を除く状態条件付き行動抽象化~\cite{kwak2024}
などが提案されている（\ref{sec:related}章）．

われわれの先行研究~\cite{naka_gi58}では，各候補手を打った後の盤面（以下，結果盤面）に階層的クラスタリングを適用し，
各クラスタの代表手のみを探索対象に残すことで候補手を削減する手法を提案した．
結果盤面でクラスタリングするのは，外乱のあるカーリングでは「どこを狙ったか」よりも
「その手がどのような盤面を引き起こすか」によって手の役割が決まると考えたためである．
本論文では，この手法をMCTSに拡張したものをClusterMedoidと呼び，既存手法として扱う．
ClusterMedoidは，各クラスタの代表手として盤面上で最も中心的な候補（medoid）を選ぶが，
この選び方は手の得点期待値を考慮していないため，代表手が有望な手になるとは限らない．
また先行研究では，全候補を探索する手法が選んだ手との一致率で性能を評価していたが，
計算予算が限られた全探索の選択は正解の代わりにならないという問題もあった．

そこで本論文では，結果盤面によるクラスタは保ったまま，
クラスタの採用と代表手の選出に得点期待値を用いる手法ClusterValueを提案する．
ClusterValueは，各候補手の得点期待値を少数のロールアウトで安価に推定し，
その平均値（クラスタ価値）が高い上位のクラスタから，それぞれ推定値が最大の候補を代表手として探索木に残す．
さらに，木の中で手を評価するたびに外乱ありで打ち直す外乱込み評価を組み合わせ，
「狙った結果」ではなく「その手を試みる価値」を評価する．

性能は，各候補手を外乱ありで200回ロールアウトして求めた得点期待値（以下，審判値）を正解の基準とし，
選んだ手と最良手との審判値の差（regret）で評価した．
層化抽出した500局面で，物理シミュレーションの回数を揃えた等予算の条件で比較した結果，
提案手法は既存手法ClusterMedoidよりregretが22\%小さく，候補を絞らない全探索も有意に上回った．
その利得は計算予算が小さいほど大きかった．

さらに，結果盤面のクラスタが人間にとって意味のある単位になることを，盤面の図を用いて示した．
クラスタは手を結果の種類でまとめ，相手の中心の石を取り除くような他と似ていない最良手や，
即時の得点は低いがエンド全体では同等に有利な別の手を，それぞれ独立したまとまりとして示す．
また，結果盤面による分割は，VOOTのような行動空間の分割よりも価値のまとまった領域を作ることを示した．

本論文の構成は次のとおりである．
\ref{sec:related}章で関連研究を述べ，\ref{sec:method}章で既存手法と提案手法を説明する．

\ref{sec:future}章で今後の課題を述べる．

\section{提案手法}
\label{sec:method}
% このセクションではまず既存手法がどういうもので、今回提案する手法はどういうものなのかを説明する。それから、新たに追加したギミック（今回だと例えばmedoidの選び方を変えたとか、得点期待値の評価値を加えたとか、おおまかな説明をさらにサブセクションとして確立する。それでこのセクションを読めば提案手法がどんなものなのかが分かる。この後に続く実験セクションで読み手にこの提案手法がどのように評価されたのかを意識させる。）

本論文で扱う手法は，いずれもMCTSの各ノードで候補手生成器が$N$個の候補手$a_1,\dots,a_N$を生成し，
それぞれを外乱なしでシミュレーションして結果盤面$s_1,\dots,s_N$を求めたうえで，どの候補手を子として残すかだけが異なる．
既存手法ClusterMedoidは，結果盤面をクラスタリングし，各クラスタで盤面上最も中心的な候補を代表手として残す．
提案手法ClusterValueは同じクラスタを用いたまま，次の3点を変更する．
一つ目，各候補手の得点期待値を少数のロールアウトで推定し，クラスタの価値を求める（\ref{sec:method-estimate}節）．
二つ目，代表手をmedoidではなくクラスタ内で推定値が最大の候補とし，価値の高い上位のクラスタだけを子として残す（\ref{sec:method-select}節）．
三つ目，木の中で手を評価するたびに外乱ありで打ち直す外乱込み評価を用いる（\ref{sec:method-noisy}節）．

\ref{sec:exp}章では，これらすべての変化について検証し, 候補を絞ること自体の利得を全探索との比較する.

\subsection{既存手法：ClusterMedoid}
\label{sec:method-medoid}

ClusterMedoidは，先行研究~\cite{naka_gi58}の候補削減をMCTSの各ノードに適用した手法である．
まず，結果盤面どうしの距離$d(s_i, s_j)$を，次の8項目の重み付き和として定義する．
% TODO:もうちょっときれいな表にする
\begin{enumerate}
\setlength{\itemsep}{0pt}
\item 元の盤面にあった石の移動量の差
\item 投げた石の停止位置の差
\item 石の有無（場外に出たかどうか）の不一致
\item 石が属する領域（ハウス内，ガードゾーン，それ以外）の不一致
\item 既存の石に触れたかどうかの不一致
\item 投げた石と最も近い石との距離の差
\item その時点で数えた得点の差
\item No.1ストーンを持つチームの不一致
\end{enumerate}
% 実装: experiments/mcts_shared.cpp distDelta (重み 2/4/30/12/15/5/8/10)
この距離に基づき，平均連結法による階層的クラスタリングで候補手を$K_c = \lceil rN \rceil$個のクラスタに分割する（$r=0.2$）.
各クラスタからはクラスタ内の他の候補との距離の総和が最小となる候補（medoid）を代表手とし，すべてのクラスタの代表手を子とする．

ClusterMedoidの代表手の選び方は，盤面の中心性のみに基づいており，手の得点期待値を考慮していない．
そのため，同じクラスタに得点期待値の高い候補と低い候補が混在する場合や，得点期待値の低いクラスタが多数を占める場合には，有望でない手に探索予算が割かれる．
先行研究~\cite{naka_gi58}でも，代表点の選び方の改善と，大きなクラスタからの代表の選び方が課題として残されていた．

\subsection{得点期待値の推定とクラスタ価値}
\label{sec:method-estimate}
ClusterValueはまず各候補手$a_i$について，その結果盤面からエンドの終わりまでのロールアウトを$R_{\mathrm{pre}}$回行い，エンドの純得点の平均$\hat{e}_i$を求める．
候補手を打った時点でエンドが終わる場合は，そのエンドの得点をそのまま用いる．次に，ClusterMedoidと同じ手順で候補手を$K_c$個のクラスタ$C_1,\dots,C_{K_c}$に分割し，
各クラスタの価値（クラスタ価値）をメンバーの推定値の平均
\begin{equation}
v(C_c) = \frac{1}{|C_c|}\sum_{i \in C_c} \hat{e}_i
\label{eq:cluster-value}
\end{equation}
とする．
$R_{\mathrm{pre}}$は小さい（本論文では5回）ため，個々の候補の推定値はばらつきが大きい．そのため, クラスタ単位で平均を取ることでばらつきを抑え, どの種類の結果が有望かを比較できる．

\subsection{代表手とクラスタの選び方}
\label{sec:method-select}
ClusterValueはクラスタをクラスタ価値$v(C_C)$を降順に並べ，上位$K$個のクラスタから，それぞれ得点期待値$\hat{e}_i$が最大の候補を代表手として子にする．
ただし，全候補の中で$\hat{e}_i$が最大の候補が属するクラスタは，価値の順位によらず必ず採用する．
クラスタ価値は平均であるため，有望な手が価値の低い手と同じクラスタにあるとそのクラスタの価値は低くなるが，この規則によって推定値が最も高い手は必ず子に残る．
子の数$K$は，子1つあたりに確保したい訪問回数$V$を用いて$K=\max(1, \lfloor P/V \rfloor)$とする．
本論文では$V=50$とし，$P=200$のとき$K=4$である．
既存手法がすべてのクラスタの代表を子とするのに対し，提案手法は子を少数に絞り，浮いた予算を1つの子あたりの訪問回数の増加に割り当てる．

\subsection{外乱込み評価}
\label{sec:method-noisy}
通常のMCTSの木は, 外乱なしでシミュレーションした結果盤面を子の状態とする．この決定的評価では狙いどおりに投げられた仮定の下での価値で評価される．一方，実際の対戦では手は外乱を伴って実行されるため，わずかなずれで結果が大きく変わる手は，決定的評価では考慮することが難しい．
本論文で正解の基準とする審判値も，外乱ありで打ち直した結果の平均と定義する.

外乱込み評価では，木の構造（候補手の生成，クラスタリング，候補の選別）は外乱なしの結果盤面から作ったまま，価値の評価だけを外乱込みで行う．
具体的には，プレイアウトのたびに選んだ手をその時点で到達している実際の盤面から外乱ありでシミュレーションし直し，得られた盤面を次のノードへ運ぶ．
葉のロールアウトも，この外乱込みで到達した盤面から行う．
ClusterValueの事前推定でも，候補手を毎回外乱ありで打ち直してからロールアウトする．これにより，各ノードの価値は, その手順を外乱のもとで試みたときの得点期待値の推定となる．

\subsection{実験の目的}
本実験の目的は，提案手法ClusterValueの性能を，既存手法ClusterMedoidおよび候補を絞らない全探索と，計算予算を揃えた条件で比較することである．特に次の3点を明らかにする．
\begin{enumerate}
\setlength{\itemsep}{0pt}
\item 外乱込み評価を加えると，各手法の性能はどう変わるか
\item 全探索と比べて，どのような計算予算のときに候補を絞る方が優れるか
\item 代表手の選び方（既存手法のmedoidと提案手法の得点期待値）の違いは，性能にどう影響するか
\end{enumerate}

また，本実験で得たクラスタは後述の視覚的評価にも用いる．

\subsection{比較手法}
% A1とかA2, A9とかは分かりずらいからやめる.
比較する手法は次の5つである．
\begin{itemize}
\setlength{\itemsep}{0pt}
\item AllGrid：全候補を子とする全探索．
% ルートの子は平均70.6個になる．
\item ClusterMedoid：既存手法．
% ルートの子は$\lceil 0.2N \rceil$個（平均14.4個）．
\item ClusterValue：提案手法．
% ルートの子は4個．
\item RandomK：ClusterMedoidと同じ数の候補を無作為に選んで子とする手法．
\item RandomK4：ClusterValueと同じ4個の候補を無作為に選んで子とする手法．
\end{itemize}

RandomKはmedoidによる選び方を，RandomK4は得点期待値による選び方を，それぞれ同じ子の数の無作為な選び方と比べるための対照である．
各手法を決定的評価と外乱込み評価の両方で実行した．ただしRandomK4は外乱込み評価のみである．

\subsection{評価指標}
正解の基準として，各局面の全候補手について，候補手を外乱ありで打ち直してからエンドの終わりまでロールアウトすることを200回繰り返し，手番側から見たエンドの純得点の平均を求めた．これを審判値$q$と呼ぶ．
審判値は「その手を試みる価値」の推定であり，探索木を用いないため各手法の実装に依存しない．
手法が選んだ手$a$のregretを$q^{*}-q(a)$とする．ここで$q^{*}$は局面内の審判値の最大値であり，regretは小さいほど良い．
審判値の標準誤差は約0.10点であるが，1位と2位の候補の審判値の差は中央値で0.073点とこれより小さく，審判値だけでは判断するのが難しい.
そこで, 最良手との一致率ではなく，値の差であるregretで評価する．

さらにregretを，選別で最良手を落としたことによる損失（選別損失．$q^{*}$と，ルートの子に残った候補の審判値の最大値との差）と，残りの損失（木の損失．子の中から最良のものを選べなかったことによる損失）の和に分けて分析する．

\subsection{実験結果}

\subsubsection{全体の比較}
\tabref{tab:main}に各手法のregretを示す．
外乱込み評価の条件では，提案手法ClusterValueのregretが0.309と最も小さかった．
これは等予算の全探索AllGridより小さく（$p=2\times10^{-4}$），
既存手法ClusterMedoid（0.396）より22\%小さい（$p=4\times10^{-8}$）．
外乱込み評価の条件で見た局面単位では，ClusterValueの方がregretが小さかった局面は，AllGridに対して297，ClusterMedoidに対して282であり，大きかった局面はそれぞれ198と205であった．
決定的評価の条件でも，ClusterValueはClusterMedoidより有意に小さく（0.423と0.488，$p=6\times10^{-4}$），
AllGrid（0.418）とは差がなかった（$p=1.0$）．

\label{tab:main}

手法 & 決定的評価 & 外乱込み評価 \\\hline

\subsubsection{外乱込み評価の効果}
外乱込み評価は，候補の選び方によらずregretを下げた（\tabref{tab:main}の左右の列）．
regretの減少は，AllGridで0.084（$p=3\times10^{-4}$），ClusterMedoidで0.092（$p=8\times10^{-8}$），ClusterValueで0.114（$p=9\times10^{-15}$）であった．
ClusterValueのregretを分解すると，選別損失は0.230から0.211とほぼ変わらず，木の損失が0.193から0.098に半減していた．
ここから分かることは, 残した子の評価が正確になったことによって改善されたと推測できる.また，選んだ手の審判値の標準偏差は外乱込み評価の有無によらず1.68であった．外乱込み評価によって安全な手を好むようになったのではなく，外乱のもとで実際に実現する価値の高い手を選ぶようになったと解釈できる．
ただし審判値も外乱込みで求めているため，この改善の一部は，木の評価のルールを正解の基準のルールに揃えたことによると考えられる．

\subsubsection{計算予算と全探索との比較}
$P=200$では，AllGrid+Nは全候補を子に持つため選別損失は0であり，regret 0.334はすべて木の損失である．これに対してClusterValueは，選別損失0.211を払う代わりに木の損失を0.098に抑えている．平均70.6個の子に予算を分散させると各子の評価が不十分になり，選別による損失を払ってでも少数の有望な子を厚く評価した方が良い手を選べることが分かる．

\begin{figure}[tb]
\centering
\includegraphics[width=\columnwidth]{figures/fig_budget.png}
\caption{プレイアウト予算$P$を変えたときのregret．実線は最終投を除く168局面，破線は最終投を含む200局面 (いずれも5シードの平均)．横軸は200局面での1局面あたりの物理シミュレーション回数の平均}
\label{fig:budget}
\end{figure}

この利得が予算の不足によるものであれば，予算を増やすと利得は縮むと予想される．そこで500局面の先頭200局面について，$P=100$〜$800$でClusterValueと外乱込みAllGridを比較した（\figref{fig:budget}）．最終投を除く168局面では，両者のregretの差は$P=100$の$-0.094$（$p=2\times10^{-5}$），$P=200$の$-0.060$（$p=3\times10^{-5}$）から，
$P=400$の$-0.016$（$p=0.12$），$P=800$の$-0.002$（$p=0.17$）まで単調に縮小し，どの予算でもClusterValueの方が悪くなることはなかった（$p$は片側のWilcoxon検定）．
同程度のregretに達するのに必要なシミュレーション回数で比べると，ClusterValueは全探索の約5〜6割で済んでいる．
たとえばClusterValueの$P=100$（3.9万回）の0.360は外乱込みAllGridの$P=200$（6.4万回）の0.358と，$P=200$（6.5万回）の0.298は$P=400$（12.2万回）の0.292とほぼ同じ結果を示す．

一方，エンドの最終投では得点につながる手が狭い範囲の少数の手に限られることが多く，事前推定による選別でその手を落としやすい．そのため最終投を含めた200局面では，$P\geq400$で外乱込みAllGridの方がregretが小さくなった（\figref{fig:budget}の破線）．500局面全体でも，最終投の32局面ではClusterValueのregretが外乱込みAllGridより0.287大きい．

\subsubsection{代表手の選び方の影響}
子の数が同じ4個どうしで比べると，無作為に選ぶRandomK4の0.552に対し，得点期待値で選ぶClusterValueは0.309であった（$p=1\times10^{-43}$）．
一方，既存手法のmedoidによる選び方は，同じ数を無作為に選ぶRandomKと差がなかった（外乱込み評価で0.396と0.383，決定的評価で0.488と0.491，いずれも$p>0.8$）．
結果盤面のクラスタで候補を分けても，その中からどの手を残すかを価値で決めなければ性能は上がらない．

既存手法との差がどのような局面で生じるかを，最良手（審判値が最大の手）が属するクラスタの大きさで局面を分けて調べた（\tabref{tab:csize}）．
最良手のクラスタが6〜10手の局面では，ClusterValueのregretが外乱込みClusterMedoidより0.090小さかった．
大きいクラスタほど，medoidが価値の低い手を代表に選ぶ機会が多いためである.

\subsection{実験のまとめ}
以上の3つの問いに対する結果をまとめる．
まず，外乱込み評価はどの手法でもregretを下げ，その効果は主に木の損失の減少によるものであった．
つぎに，候補を絞ることの利得は計算予算が小さいほど大きく，最終投を除けばどの予算でも提案手法は全探索の利得を上回った.
% TODO: 図を載せる
ただし最終投では，選別で最良手を落とすため全探索の方が良い．
さらに，得点期待値による代表手の選び方は無作為な選び方を大きく上回ったが，medoidによる選び方は無作為な選び方と変わらなかった．
以上から，提案手法の性能の向上は，得点期待値に基づく候補の選別と外乱込み評価によってもたらされたといえる．

\section{考察}
\label{sec:discussion}
% 実験の説明がおわったあとのセクションでは、実験結果から導かれる考察について書いていく。今回のテーマだと軸は二つあって、一つは既存手法との差分を性能面で評価したらどうなったのかを明記すること。もう一つは、視覚的の評価が考えられるようになったということを示そう。具体的には、「人間にとって意味がある風にこの提案手法のクラスタリングはできるよ」ということが伝わるように書きたい。この二つのサブセクションだけあれば十分。ボロノイ領域との関係もここで提言しておく。一つのサブセクション内に話をまとめれば十分かな。

\subsection{既存手法との性能の差}
既存手法ClusterMedoidと提案手法は同じ結果盤面のクラスタを用いており，違いは代表手の選び方，採用するクラスタの数，評価のルールの3点である（\tabref{tab:diff}）．同じ外乱込み評価のルールで比べると，提案手法のregretは既存手法より0.087（22\%）小さかった．既存手法の代表手は価値を見ないため，約14個の子を持っても，同じ数を無作為に選ぶ場合と性能が変わらなかった．これに対して提案手法は，クラスタ価値で4個のクラスタを選び，その中で推定値が最大の手を代表とすることで，子の数を減らしながら有望な手を残している．差が大きいのは最良手のクラスタが大きい局面であり，大きなクラスタの中から盤面上の中心ではなく価値の高い手を選ぶことが，既存手法との差を生んでいる．
これは，先行研究~\cite{naka_gi58}で課題とした代表点の選び方と大きなクラスタの扱いに対する一つの解決である．
また，先行研究では全探索との一致率で評価していたが，等予算の外乱込み全探索AllGrid自体のregretは0.334であり，全探索の選択を正解とみなすことはできない．
審判値に基づくregretで評価したことで，提案手法が全探索を上回ることを示せた．

\subsection{人間にとって意味のあるクラスタ}
提案手法のクラスタは，探索の単位であるだけでなく，人間が盤面を見て理解できる単位にもなりうる．
\figref{fig:cases}に，相手の中心の石を取り除く手が最良となる2つの局面について，全候補のクラスタと，最良手A，別の道Bの結果盤面を示す．
2つの局面は，どちらも相手（青）がNo.1ストーンを持ち，手番の赤が負けている局面である．
最良手Aはいずれも相手のティー付近の石に弱く当てる手であり，投げた直後の盤面で数えた得点（以下，即時得点）を，
局面1では相手の石2個（と奥の自分の石1個）をプレーの外に出して$-1$から$+4$に，局面2では相手のNo.2を出してNo.1を奥へ押しやり$-2$から$+2$にする（(c)）．
これらの手の結果盤面は他の候補と似ておらず，最良手のクラスタは局面1で2手，局面2で1手だけからなる．
(b)のように，Aの投げた石は別のクラスタの手とほぼ同じ位置に止まるが，他の石の動き方が異なるため別のクラスタに分かれている．
すなわちクラスタは，狙いや投げた石の止まる位置ではなく投げた後の盤面全体で手をまとめており，相手の石を取り除く手が多数のドローやガードに埋もれずに現れる．

\subsection{ボロノイ領域との関係}
VOO~\cite{kim2020voot}は，評価済みの行動を母点として行動空間をボロノイ分割し，最良の母点のセルの中を重点的に探索する．
提案手法も，候補を領域に分けて各領域を1つの代表で扱い，推定値が最大の候補を含むクラスタを必ず採用する．
各候補を最も近い代表に割り当てた領域を，結果盤面の距離による一般化したボロノイ領域とみなせば，提案手法はVOOと同様に最良の領域を重点的に探す方法と位置づけられる．
ただし距離$d$はベクトル空間の距離ではなく，平均連結法のクラスタは厳密にはボロノイ領域ではない．
両者の本質的な違いは，どの空間で近さを測るかにある．
そこで，VOOが前提とする「近い行動は近い価値を持つ」という性質が，行動空間と結果盤面の空間のどちらでよく成り立つかを調べた．
\figref{fig:space}(a)に1つの局面の候補を行動空間に置いて結果盤面のクラスタで色分けしたものを，(b)に468局面で候補を同じ数の領域に分けたときの$\eta^2$を示す．

\section{今後の課題}
\label{sec:future}
% ここでは今後の課題について書く。実験結果から分かることや、今の提案手法の弱みを明記し、それをどのように改善したいのかを書く。

実験から，提案手法には次の弱みがあることが分かった．
まず，エンドの最終投では事前推定による選別で得点につながる少数の手を落とし，全探索より性能が下がる．
最終投の局面だけ全探索に切り替えると，$P=200$の500局面全体のregretは計算上約0.02下がる．
次に，計算予算が大きくなると全探索との差は小さくなる．
提案手法の利点は予算が小さい場合に限られるため，持ち時間や探索予算に応じてクラスタリングを使用するか否かを検討する必要がある．
さらに，得点期待値に基づく選別はルートノードだけに適用しており，深さ1以降のノードでは既存手法の規則を用いている．
事前推定のコストを抑えながら，内部のノードにも価値に基づく選別を広げることが課題である．

\section{おわりに}
\label{sec:conclusion}
% このセクションでは全体の論文の概要を取りまとめる。このセクションで書かれていることは、"はじめに"のセクションで示された内容と論理的に一貫するように全体のまとめについて書くので、そこまで長い文章になる必要は無い。

本論文では，デジタルカーリングのMCTSにおける候補手の削減について，結果盤面のクラスタを保ったまま，クラスタの採用と代表手の選出に得点期待値を用いるClusterValueと，外乱込み評価を組み合わせた手法を提案した．
審判値に基づくregretで500局面を等予算で比較した結果，提案手法は既存手法ClusterMedoidよりregretが22\%小さく，候補を絞らない全探索も上回った．
その利得は計算予算が小さいほど大きく，最終投を除けば全探索の約5〜6割の計算量で同程度の品質が得られた．
性能の向上は，得点期待値に基づく選別と外乱込み評価によるものであり，medoidによる代表手の選び方は無作為な選び方と変わらなかった．
また，結果盤面のクラスタは手を結果の種類でまとめ，相手の中心の石を取り除くような他と似ていない最良手や，一時的な得点は低いがエンド全体では同等に有利な別の道を，独立したまとまりとして示せることを確認した．
今後は最終投での選別の改善と，持ち時間のある対戦および人間による評価を可能にすることを目標とする.
