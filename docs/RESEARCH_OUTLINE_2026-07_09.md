3. **9月 (査読対応)**: アブレーションの結果、**性能の源泉は価値スクリーン (E[score] 上位 K 個の選択) で、クラスタ構造そのものの性能への寄与はゼロ**と確定した。
   予算スイープでは、削減の利得が低予算ほど大きく、予算を増やすと単調に縮むことを確認した。
   クラスタリングの主張は「意思決定品質を落とさずに、エリア単位の説明可能性と推定精度を与える表現」に整理した。

## 2. 共通の評価基盤 (本論文の「評価設定」節の素材)

### 2.1 探索と候補
- 1 投ごとに候補プール (generatePool: ドロー/ヒット/フリーズ/ガード等) を作る。**候補数 N = 33〜153 (500局面の平均 70.6, 中央値 61)**。
- MCTS: 深さ 3、プレイアウト予算 **P=200**、葉で R=10 回ロールアウト。木の UCB は **negamax** (7/14 修正後)。エンドを跨ぐ枝は終端の葉として扱う (7/23 修正後)。
- ロールアウト方策 (6/29 から): 毎手 6〜10 個の候補 (ハウスを覆うドロー 6 + 相手 No.1 へのヒット 2 + ハウス内ならフリーズ + 石が少なければガード) から ε-greedy (ε=0.3) で選ぶ。
  それ以前の「4×4 グリッドのドロー 16 手のみ」より現実的で、1 ステップあたりのコストも安い。
- 報酬: そのエンドの純得点 (root 手番視点)。**勝率やハンマーの価値は見ていない (単一エンドの目的)**。

### 2.2 審判 (正解基準) — `score_move_experiment`
- 各候補を **K=200 回、初手から外乱ありで打ち直してロールアウト**し、q_ref = E[単一エンド純得点] を求める (「その手を試みる価値」)。
- 木を使わないので、7月の 2 つの木のバグの影響を受けない (全期間の値が有効)。

### 2.3 指標と統計
- **regret = q\* − q_ref(手法が選んだ手)** (q\* = その局面での q_ref 最大値)。
- 損失の分解 (run500 から): **screen_loss** = q\* − (子に残った代表手の中で最良の q_ref)、**tree_loss** = regret − screen_loss。
- 統計: 局面ごとに 5 seed を平均 → Friedman 検定 → 対ごとに Wilcoxon 符号順位検定 + Holm 補正、効果量 d、勝敗数 (Demšar 2006 に準拠)。
  スクリプト: `scripts/aggregate_reinvest.py`, `scripts/regret_stats.py`。
- 等予算: 物理シミュレーション回数 `actual_total_sims` で揃える (P=200 で 1 局面あたり 6.3〜8.0 万回程度)。

### 2.4 局面セット
| セット | 構成 | 用途 |
|---|---|---|
| `test_positions50` | 既存 8 + 新規 42 | 7月の regret 全般、run50v2 |
| `test_positions200` | 先頭 50 = 上と同じ + 層化 150 (`pick_more_positions.py --seed 23`) | run200 |
| `test_positions500` | 先頭 200 = 上と同じ + 層化 300 (`pick_positions_stratified.py --seed 31`) | run500・アブレーション。予算スイープは先頭 200 |

層化 300 の内訳: empty_early 40 / sparse_early 30 / takeout mid・late 40・40 / freeze 30・30 / draw 20・20 / crowded 25・25 (shot 15 は除外)。
**注意: 最終ショット (r=1) は先頭 200 に 32 局面 (16%) が集中しており、500 局面全体では 6.4%。**

## 3. 実験カタログ

### 前提 (6月): 7月の出発点
- **GI58**: Proposed (= A2) を原始モンテカルロで評価。指標は AllGrid との一致率・クラスタ一致率。
- **6/17 再投資実験** (8局面): 節約した計算を深さ 5 に回す案とロールアウト増に回す案は、どちらも逆効果だった。❌ (両方のバグがある木)。
- **6/22 モード分離実験** (8局面): Proposed の Mode Recall は 0.65〜0.71 で、RandomK の 0.93〜0.99 に負けた。
  原因は、候補が多い混雑局面 (N>120) で平均連結法が「1 個の巨大クラスタ (~80%) + 多数の単独クラスタ」に退化すること。⚠️ (クラスタ退化という所見は木と無関係)。
- **6/29 方針転換**: AllGrid@P200 の選択を K=200 の審判と照合すると、最良手を外す局面が多かった (例: g7881 で q\*=+1.86 の手を 20 seed すべてで外す)。
  → **正解は審判 q_ref で定義**し、**目的を単一エンドの E[score] 最大化**に変更。審判に得点ヒストグラムの出力を追加。

#### E05 木の深さの価値 treedepth (7/10、negamax で再測定 7/15) ❌
- 設定: test_positions_depth (52局面)、深さ 2/3 × seed 42–44。Δ = q\* − q_ref(深さ k の MCTS が選んだ手)。
- 結果: Δ は r=2 で 2.02、r=3 で 1.52、r=4 で 0.24。negamax 修正後も 2.23 / 1.55 / 0.18 とほぼ同じだが、**選んだ手の一致率は r=2 で 0%、r=3 で 5%、r=4 で 54%** とほぼ総入れ替え。

#### E06 審判の監査: 収束と ε 感度 (7/15–7/16) ✅
- 収束: K=200 での q_ref の標準誤差は約 0.10 点 → **値そのものは収束している**。ただし 1 位と 2 位の差の中央値 0.073 は標準誤差より小さい → **約 7 割の局面で「最良手がどれか」は不安定**。
- ε 感度: ε ∈ {0, 0.1} を K=200 で追試し、既定の 0.3 と比較。候補順位の Spearman ρ 中央値は **0.76〜0.82** (順位は ε に頑健)。最良手の一致は 28〜36%、q\* のずれは +0.05〜0.07。
- 帰結: 「値」を使う regret 系の指標は頑健。「審判の最良手と一致したか」系の指標は割り引いて読むべき。
- **論文での使い道**: 評価設定の節で、GI58 の一致率評価から regret に移った根拠になる。データ: `reinvest_experiment/referee_eps/`。

### Phase ② 7/16–7/27: 深さの問いと木のバグ

#### E07 深さ対決シリーズ (7/16–7/23) — 自己対戦は ❌、修正木の regret は ✅
- (a) A7 の深さ 3 vs 深さ 1 (negamax, P=200, 2エンド 50局): 深さ 3 の 17勝24敗9分 = 41.5% (p=0.35)。
- (b) `--noisy-tree` (open-loop で毎回打ち直す木, 481d7be) を両者に適用して再戦: 18勝22敗10分 = 45.0% (p=0.64)。
- (c) フェーズ適応 (前半は深さ 1 × P100、終盤は深さ 3 × P500) vs 一定の深さ 1 × P200: 14勝24敗12分 = 36.8%、平均 −0.64 点 (95% CI が 0 を含まない)。
- (d) A1 の深さ 1 の regret 0.671 vs 深さ 3 の 0.781 (深さ 1 は sims も 32% 少ない)。
- 状態: (a)(c)(d) はエンド跨ぎバグ下、(b) はガード飢餓バグ下での計測 → **❌**。
- **修正木で有効な深さの数値 (run50v2, 50局面 × 5 seed)**: A1d1 **0.470** vs A1 (深さ 3) **0.514**。深さ 1 の 27勝14敗、Wilcoxon p=0.058 (有意差なし。この文書の作成時に再計算)。
  言えるのは「**深さ 3 は深さ 1 に対して優位を示さない**」まで。自己対戦による深さ対決は、修正木では再戦していない。

#### E08 深さ 3 の敗因解剖 → エンド跨ぎ汚染バグの発見と修正 (7/23–7/25) ⚠️
- 解剖 (バグ下): 深さ 1 と深さ 3 の手の一致率は 6〜18%。終盤で手が分かれると、深さ 3 の手は審判の期待値で −0.45 点/回。Hit→PostGuard ×14、Hit→Draw ×8 (石を出す手がガードやドローに置き換わる)。
- **バグ 1 (エンド跨ぎ汚染)**: 木の枝がエンドの最終ショットを跨ぐと、次のエンドのロールアウト得点を価値にしていた。
  「得点した側は次エンドのハンマーを失う」規則と組み合わさり、**今得点しない消極的な手を系統的に好む**誤った目的になっていた。
- **バグ 2 (ガード飢餓)**: noisy 木で跨いだ子の訪問統計が更新されず、相手の最終ショットが「固定の 1 候補」扱いになっていた。
- 修正 (e9f0dde): 跨いだ子を終端の葉とし、現エンドの得点を報酬にした。
- 検証 (seed42): 終盤の Δq は −0.451 → **−0.086**、Hit→PostGuard は 14 → **0**、A1 (深さ 3) の regret は 0.852 → **0.508**。
- 論文での扱い: 「検証基盤を頑健にした」として一文程度 (アブスト時の方針)。

#### E09 修正木での 6 手法再走 run50v2 (7/25) ✅
- 設定: test_positions50 × 5 seed、P=200、R=10、深さ 3、審判 K=200。
- 結果: **A1 0.514 / A2 0.506 / A5 0.505 / A7 0.502 / A8 0.511 / A9 0.508**、Friedman p=0.989 (完全に横並び)。
- フェーズ別に分解すると、序盤と中盤は修正前後で変わらず、旧表の差はすべて終盤から来ていた。
  価値を見ない手法群はバグの直撃を受け (A1 の終盤 1.18→0.61)、スクリーン系は R_pre の end_done ガードのおかげで**たまたまバグの影響を受けなかっただけ**だった。
- 修正後の sims は約 55k/局面 (存在しない次エンドのロールアウトがなくなり、約 1/3 に)。
- 論文での扱い: アブストの表 (A1/A2/A9 の 3 手法、Friedman p≈0.87) の出典。本論文では 500 局面の表に置き換わる。

### 執筆上の最大の論点: タイトルと主張の軸
アブストのタイトルは「価値考慮型クラスタリングの適用」だが、データ上、**性能の主因は価値スクリーンで、クラスタは性能コストゼロの表現**である。
推奨する書き方は次の通り:
- 提案手法を「ClusterValue = クラスタ表現を保ったまま価値で選ぶ」と定義する。
- 性能 (C1〜C4) と表現の価値 (C5) を分けて書く。
- A8N (クラスタなし) を正直に載せる。これは R2⑤「クラスタリングによる削減の効果まで示せ」への誠実な回答になり、アブストで書いた「性能を損なわずに分析的な価値を得る」路線とも矛盾しない。
- アブストで約束した「実行リスクを統合したクラスタ価値」については、λ では性能が上がらなかった (説明のための手段) ことと、外乱込み評価 (実現性の考慮) が実質的な答えになったことを、セットで書くと流れが通る。
